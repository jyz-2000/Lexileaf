## 『 词笺 Lexileaf 』：一个专注于单词本制作、排版、打印的应用

词笺（Lexileaf）是一款离线单词本制作 App，专为想把单词真正“管起来”的人设计，制作属于你自己的单词“红宝书”。词笺把文件管理、词表编辑、格式排版、星标管理和 PDF/ Excel导入导出收进一个轻巧界面里，单词整理、迁移、打印一站式搞定。

### 如何获取 ⬇

#### 华为用户可直接再官方应用商城安装，其它安卓手机（例如小米、vivo、oppo...）由于官方不允许个人上架，可在本页面下载“app-release.apk”并安装，安装可能会有外部应用风险弹窗，无视即可。iOS版暂无开发计划。

特色：
- 自由创建文件夹和单词表，打造“私人词库”
- 直接导出“印刷级”PDF单词表，排版精致
- 灵活编辑文字的加粗、下划线和星标
- 通过Excel文件实现数据的导入导出和迁移
- 完全离线使用，数据全部本地保存

功能：
- 多级文件夹管理：支持文件夹创建、重命名、删除；支持单词表创建、重命名、移动、删除
- 单词编辑：每条单词包含英文词条和多行中文释义，支持新增、编辑、删除
- 格式排版：中文释义可单独设置加粗、下划线；保存后重新打开、导入、导出都能保留
- 星标管理：支持批量选择星标词，在列表中高亮展示，导出时也会同步标记
- 列表操作：单词条目支持左滑删除，操作直接，不绕弯
- 排序切换：支持五种导出顺序：从新到旧、从旧到新、A-Z、Z-A、随机打乱；导出顺序可独立选择，不影响本地保存顺序
- Excel 导入导出：支持 .xlsx 导入，可导入为新单词表，也可并入当前单词表的前/后；导出为无表头 .xlsx，保留文本样式和单词星标
- PDF 导出：基于内置模板离线生成排版精致的 PDF 文件，方便打印使用
- 本地存储：所有单词库和设置都保存在本机私有空间，导入导出通过系统文件选择器完成
